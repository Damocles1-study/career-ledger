# 路线台账 · 体制内 vs 大厂

在线地址：https://damocles1-study.github.io/career-ledger/

上海、苏南（苏州 / 南京 / 无锡常州）、苏中、苏北六个地区，11 条路线（公务员、乡镇公务员、选调生、事业编、中小学教师、高校行政、国企、银行、互联网大厂、中小厂、外企）按年模拟到退休：

- 到手收入、公积金、职业年金，企业路线现算五险一金与个税
- 存款／净资产曲线，结婚、买车、养娃、买房事件
- 本科 / 硕士 / 博士三种学历，追平年龄
- 男女双视角：退休年龄、养老金年数、婚嫁习俗、生育对职业的影响
- 上岸概率乘回去的期望值；体制内财政、AI 冲击、35 岁三类情景
- 钱以外的维度加权打分

纯静态页面，无外部依赖，所有计算在浏览器本地完成。

## 改数据

所有口径集中在 `data.js`（城市、路线、情景、性别默认值），模型在 `app.js` 的 `income()` 与 `simulate()`。数据为 2026 年 11 月口径，出处见页面最后一节。

本页只做决策辅助，不构成就业或投资建议。
